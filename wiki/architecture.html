ארכיטקטורה

סקירה מערכתית, מבנה תיקיות, זרימת נתונים, והחלטות עיצוב מרכזיות של המערכת.

תרשים מערכת

כלל מרכזי

הפרדת שכבות קריטית

תיקיית core/ אסור לה לייבא React, R3F, או כל קוד UI. היא עובדת רק עם טייפסקריפט טהור ומתמטיקה של Three.js. זה מאפשר הרצת טסטים ללא DOM והרצה ב-Web Workers.

זרימת נתונים

יצירת מסגרת

כל שינוי במידות, פרופיל, או צורת מסגרת מפעיל את שרשרת הייצור מחדש:

User changes dimension/profile/path
        │
        ▼
useFrameInit (React hook, outside Canvas)
  - Computes JSON hash of all frame-affecting state
  - If changed: calls generateFrame()
        │
        ▼
FrameGenerator.generateFrame()
  - Polygon path? → buildMiteredBeam() per edge
  - Smooth path?  → SplineExtruder.extrudeProfileAlongPath()
  - Builds back plate from shrunk path
  - Returns { parts: PartNode[], geometries: Map }
        │
        ▼
useProjectStore.setState({ parts, meshCache })
        │
        ▼
FrameScene (inside Canvas)
  - Subscribes to parts + meshCache
  - useEffect → invalidate() → Canvas re-renders
  - Renders PartMesh for each visible part
  - Renders symmetry mirror ghosts
  - Renders cloner instances

זרימת Cloner

User adjusts slider in DecorationPanel
        │
        ▼
useClonerStore.set({ count: 12, ... })
        │
        ▼
FrameScene (subscribes to cloner store)
  - useMemo: computeCloneTransforms(pathPoints, settings)
  - Returns Matrix4[] for each clone position
        │
        ▼
Render: cloneMatrices.map((matrix, i) =>
  <mesh geometry={sources[i % sources.length]} matrix={matrix} />
)

מאגרי מצב (Stores)

useProjectStore

מאגר מרכזי - חלקים, מידות, פרופיל, מטמון גאומטריה, הגדרות מדפסת. מכיל את כל ה-CRUD של ה-Part Tree.

useSelectionStore

מצב בחירה - חלקים נבחרים, hover. מנותק מ-Project Store למניעת re-renders מיותרים.

useToolStore

כלי פעיל, toggles (wireframe, grid, build volume). שולט על מצב ה-viewport.

useRenderStore

מצב רנדור - mode (matcap/pathtracer), הגדרות חומר, סביבה.

useClonerStore

פרמטרים של ה-Cloner - כמות, offset, סיבוב, scale, step effectors, random effectors.

useFrameInit

Hook שמאזין לשינויים בכל ה-state שמשפיע על המסגרת ומפעיל ייצור מחדש דרך JSON hash.
