Data Flow

Frame Generation

User changes dimension/profile/path
        │
        ▼
useFrameInit (React hook, outside Canvas)
  - Computes JSON hash of all frame-affecting state
  - If changed: calls generateFrame()
        │
        ▼
FrameGenerator.generateFrame()
  - Polygon path? → buildMiteredBeam() per edge
  - Smooth path?  → SplineExtruder.extrudeProfileAlongPath()
  - Builds back plate from shrunk path
  - Returns { parts: PartNode[], geometries: Map }
        │
        ▼
useProjectStore.setState({ parts, meshCache })
        │
        ▼
FrameScene (inside Canvas)
  - Subscribes to parts + meshCache
  - useEffect → invalidate() → Canvas re-renders
  - Renders PartMesh for each visible part
  - Renders symmetry mirror ghosts
  - Renders cloner instances

Cloner Data Flow

User adjusts slider in DecorationPanel
        │
        ▼
useClonerStore.set({ count: 12, ... })
        │
        ▼
FrameScene (subscribes to cloner store)
  - useMemo: computeCloneTransforms(pathPoints, settings)
  - Returns Matrix4[] for each clone position
        │
        ▼
Render: cloneMatrices.map((matrix, i) =>
  <mesh geometry={sources[i % sources.length]} matrix={matrix} />
)

Key Design Decisions

DecisionChoiceRationale
CSG enginemanifold-3d + three-bvh-csgManifold guarantees watertight. BVH handles non-manifold input as fallback.
State managementZustand + ImmerStandard for R3F apps. No Provider wrapper. Works outside Canvas.
RenderingMatcap (no lights)Reliable in Electron. No HDRI dependency. No flickering.
Frame loopdemandRenders only when invalidate() called. Prevents flickering.
Frame constructionBeam + miter cutMatches real-world frame making. Clean corners.
Profile storageNormalized 0-1 pointsScale-independent. Works with any frame width/depth.
ClonerLive rendering, no bakeLike C4D MoGraph. Instant feedback. Bake as future option.
Inline stylesAll CSS inlineTailwind CSS didn't load in Electron. Inline is reliable.

Core Constraint

Critical Rule

core/ directory must NEVER import React, R3F, or any UI code. It operates on plain TypeScript types and Three.js math/geometry only. This enables testing without DOM and running in Web Workers.
