שלב 3: Import + Placement

ייבוא מודלים תלת-מימדיים חיצוניים, הוספת צורות בסיסיות, ומיקום על המסגרת.

90% הושלם

מהות השלב

מסגרת בלי עיטורים היא משעממת. שלב 3 מאפשר ייבוא מודלים מהעולם החיצוני (STL/OBJ/GLTF/PLY) ומיקום שלהם על המסגרת כדי ליצור עיצובים ייחודיים.

Import מודלים

תמיכה ב-4 פורמטים נפוצים. Auto-detect לפי סיומת קובץ. נירמול אוטומטי (מרכוז, scaling).

Primitives

5 צורות בסיסיות: Cube, Sphere, Cylinder, Cone, Torus. לבדיקות מהירות ולעיצוב.

Placement

Position/Rotation/Scale ידני דרך פאנל + Gizmo (W/E/R). כפתורי Quick Rotation. Drag-to-scrub על labels.

Wavefront OBJ.objOBJLoaderפשוט, נפוץ. תומך קבוצות ו-normals.
GLTF / GLB.gltf, .glbGLTFLoaderסטנדרט מודרני. GLB = binary compressed.

פורמטים עתידיים
  • STEP - דורש opencascade.js (~20MB WASM). Lazy-loaded.
  • 3MF - ZIP עם XML + mesh data. Parser מותאם.

זרימת Import

1. User clicks "Import" button in Toolbar
2. window.api.openFile({ filters: [STL, OBJ, GLTF, PLY] })
3. Returns { path: string, data: ArrayBuffer }
4. ModelImporter.importModel(fileName, data)
   - Auto-detect format by extension
   - Parse with appropriate Three.js loader
   - normalizeGeometry(): center, compute normals
5. useProjectStore.importModel(fileName, geometry)
   - Create PartNode { type: 'decoration' }
   - Auto-scale to 60% of picture height
   - Add to meshCache
6. Model appears in scene + part tree

בעיה ידועה

#006 - כיוון STL לא תמיד נכון

פורמט STL לא מגדיר כיוון. מודלים מגיעים מסובבים או הפוכים. ניסינו auto-rotation (PCA, bounding box analysis) - כשל עם מודלים שונים. Workaround: כפתורי Quick Rotation (Front/Back/Flip/Lay) ב-DecorationPanel.
