מדריך שימוש

הסבר מלא על מבנה המסך, קיצורי מקלדת, ו-How-To לכל פעולה במערכת.

צילומי מסך

עם כל שלב פיתוח חדש שיושלם, יתווספו לעמוד זה צילומי מסך נקודתיים לכל פיצ'ר ויכולת. כרגע המערכת ב-alpha - צילומי מסך יתווספו בהמשך.

אזורי המסך
  • שמאל - Part Tree: עץ חלקים עם selection, visibility, delete
  • מרכז - 3D Viewport: תצוגת המסגרת
  • ימין - שני tabs: Profile (עיצוב) ו-Properties (מידות)
  • למטה - Status Bar: סטטיסטיקות

How-To

יצירת מסגרת בסיסית

  1. פתח את האפליקציה - מסגרת מלבנית מופיעה אוטומטית
  2. עבור ל-tab Properties (ימין למעלה)
  3. שנה Picture Size: W ו-H (ברירת מחדל 200x300mm)
  4. שנה Frame Width (רוחב המסגרת, ברירת מחדל 40mm)
  5. שנה Frame Depth (עומק/עובי, ברירת מחדל 20mm)
  6. המסגרת מתעדכנת בזמן אמת

שינוי צורת מסגרת

  1. עבור ל-tab Profile (ימין למעלה)
  2. תחת Frame Shape בחר:
    • ▭ Rectangle - מלבן רגיל
    • ○ Circle - עיגול
    • ⬮ Ellipse - אליפסה
    • ⬡ Polygon - מצולע (3-12 צלעות)
    • 〰 Freehand - ציור חופשי
  3. המסגרת משתנה מיד

ציור פרופיל (חתך) מותאם אישית

  1. ב-tab Profile, מתחת ל-Presets בחר נקודת התחלה (Flat/Ogee/etc.) או Clear
  2. בחר Mode:
    • Edit Points - לחץ להוסיף נקודה, גרור להזיז, double-click למחוק
    • Freehand Draw - לחץ וגרור לצייר קו חופשי
  3. החזק Shift בזמן ציור/גרירה לקווים ב-45°/90°
  4. כוונן את Smooth slider (0 = חד, 5 = חלק מאוד)
  5. הפרופיל מתעדכן על המסגרת בזמן אמת
מערכת צירים

ציר אופקי = inner edge (שמאל) → outer edge (ימין)
ציר אנכי = front face (למעלה) → back face (למטה)
הבסיס (קו תחתון) נשאר קבוע תמיד - לא משתנה מ-smooth

ציור מסגרת חופשית

  1. ב-Frame Shape בחר 〰 Freehand
  2. מופיע canvas ציור - לחץ וגרור לצייר את קו המתאר של המסגרת
  3. כוונן Smooth slider להחלקת הצורה
  4. Clear למחיקה והתחלה מחדש

ייבוא מודל תלת-מימדי

  1. לחץ Import ב-Toolbar
  2. בחר קובץ STL / OBJ / GLTF / GLB / PLY
  3. המודל מופיע במרכז המסגרת
  4. בחר אותו ב-Part Tree
  5. בפאנל הימני:
    • Position / Rotation / Scale - מיקום ידני
    • Quick Rotation - כפתורי Front/Back/Flip/Lay
    • Drag axis label - גרור את ה-X/Y/Z לשינוי מהיר
  6. או השתמש ב-Gizmo: לחץ W (Move), R (Rotate), E (Scale)

הוספת Primitive

  1. לחץ + Prim ב-Toolbar
  2. בחר: Cube / Sphere / Cylinder / Cone / Torus
  3. הצורה מופיעה במסגרת
  4. הזז עם Gizmo (W)

שימוש ב-Cloner

  1. הוסף Primitive או Import מודל
  2. בחר אותו ב-Part Tree
  3. בפאנל הימני (DecorationPanel) לחץ "Add to Cloner"
  4. העותקים מופיעים מיד לאורך המסגרת!
  5. כוונן parameters:
    • Count - כמות עותקים
    • Offset - מרחק מהpath (פנימה/החוצה)
    • Rotate - סיבוב בסיסי
    • Scale - גודל
    • Z - עומק (קדימה/אחורה)
  6. Step effectors (מצטבר per clone):
    • Rot+ - כל clone מסתובב עוד קצת (ספירלה)
    • Scale+ - כל clone גדל/קטן (taper)
    • Flip Alt - כל clone שני מתהפך
  7. Random:
    • Seed - מספר random אחר = תוצאה אחרת
    • Spacing - פיזור לא-אחיד לאורך ה-path
    • Pos / Rot / Scale / Z - jitter אקראי

Multi-Source Cloner (Iterate Mode)

  1. הוסף כמה primitives/models שונים
  2. בחר כל אחד ולחץ "Add to Cloner"
  3. העותקים מתחלפים בין ה-sources ברצף (A, B, C, A, B, C...)
  4. "Remove from Cloner" - מסיר source ספציפי
  5. "Clear All" - מנקה הכל

Symmetry Mirror

  1. ב-tab Profile, סעיף Symmetry Mirror
  2. בחר מצב:
    • None - ללא שיקוף
    • ↔ Left=Right - שמאל משוקף לימין
    • ↕ Top=Bottom - למעלה משוקף למטה
    • ¼ Quarter - רבע משוקף ל-4 פינות
  3. הוסף decoration - העתקי מראה מופיעים אוטומטית
  4. הזז את המקור - המראות עוקבות בזמן אמת
  5. "Break Symmetry" - חזרה ל-None, מראות נעלמות

Wireframe Toggle

  • לחץ Wire ב-Toolbar או מקש Z
  • Wireframe מופיע/נעלם על כל החלקים
  • ברירת מחדל: ON (דלוק)
  • חלק נבחר - wireframe כחול, שאר - שחור שקוף
