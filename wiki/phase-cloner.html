שלב C: Cloner

מערכת שכפול בסגנון Cinema 4D MoGraph - פיזור אובייקטים לאורך ה-frame path עם effectors.

90% הושלם

מהות השלב

ה-Cloner הוא אחד הכלים הכי חזקים במערכת. הוא מאפשר ליצור דפוסים מורכבים על המסגרת בלחיצה אחת - פרחים, כוכבים, אלמנטים דקורטיביים - שחוזרים על עצמם לאורך כל המסגרת.

השראה: Cinema 4D MoGraph

הקונספט מבוסס על מערכת ה-MoGraph Cloner של Cinema 4D - הסטנדרט בתעשייה ל-motion graphics. אנחנו מיישמים את ה-Object mode (שכפול לאורך spline) עם effectors.

איך זה עובד

1. המשתמש מייבא מודל או מוסיף primitive
2. בוחר אותו ב-Part Tree
3. לוחץ "Add to Cloner" ב-DecorationPanel
4. העותקים מופיעים מיד לאורך ה-frame path!
5. כל slider שמשתנה → עדכון מיידי (ללא Apply)

Flow:
  DecorationPanel → useClonerStore.set()
                          │
  FrameScene ← subscribes to store
    └→ computeCloneTransforms(pathPoints, settings)
         └→ Matrix4[] for each clone
              └→ <mesh geometry={source} matrix={matrix} />

תלויות

תלוי ב:
  • שלב S (Spline) - ה-path points שלאורכם הclones מפוזרים
  • שלב 3 (Import) - מודלים מיובאים כ-source ל-cloner
  • שלב 1 (Foundation) - PartMesh לרנדור, Store למצב

Step Effectors - אפקטים מצטברים

כל clone מקבל שינוי מצטבר ביחס לקודם:

פרמטרטווחדוגמה
Rot+0° - 90°clone 1: 0°, clone 2: 15°, clone 3: 30° → ספירלה
Scale+-0.1 — +0.1clone 1: 1.0, clone 2: 1.05, clone 3: 1.1 → taper
Flip Alton/offclone 1: רגיל, clone 2: הפוך, clone 3: רגיל

כל clone מקבל jitter אקראי (seeded - תוצאות חזרתיות):

פרמטרטווחתיאור

Pos0 - 20mmריצוד מיקום (offset)
Rot0° - 180°ריצוד סיבוב
Scale0 - 1ריצוד גודל
Z0 - 15mmריצוד עומק

Multi-Source (Iterate)

אפשר להוסיף כמה מודלים שונים ל-cloner. העותקים מתחלפים ביניהם ברצף:

Sources: [Flower, Star, Leaf]
Clone 1: Flower
Clone 2: Star
Clone 3: Leaf
Clone 4: Flower   ← חוזר מההתחלה
Clone 5: Star
Clone 6: Leaf
...

כל source נבחר ב-Part Tree ומתווסף דרך כפתור "Add to Cloner".

שיקולי ביצועים

Performance
  • כרגע כל clone הוא <mesh> נפרד ב-React. זה עובד טוב עד ~40 clones.
  • מעל 60 clones → צריך לעבור ל-InstancedMesh (draw call אחד).
  • ה-matrixAutoUpdate={false} כבר מופעל - שיפור קטן.

רעיונות עתידיים

הרחבות
  • InstancedMesh - ביצועים: 1000+ clones ב-draw call אחד
  • Bake/Fuse - הפיכת clones ל-mesh אחיד (לייצוא)
  • Spline Effector - שליטה בפרמטרים דרך curve
  • Shader Effector - טקסטורה/noise שולט בפיזור
  • Weight Painting - צביעת אזורים עם עוצמת effector
  • Nested Cloners - cloner בתוך cloner
