שלב 6: Export + Production

ייצוא לפורמטי הדפסה (STL/3MF), שמירת פרויקטים, מדריך הרכבה, והכנה לייצור.

טרם התחיל

מהות השלב

כל מה שבנינו עד עכשיו הוא בתוך האפליקציה. שלב 6 מוציא את זה החוצה - לקבצים שמדפסת 3D יכולה לעבד.

Export STL

הפורמט הסטנדרטי להדפסה. Binary STL (קטן ומהיר). כל חלק כקובץ נפרד או הכל באחד.

Export 3MF

פורמט מתקדם - ZIP עם XML + meshes. תומך multi-part, colors, metadata. הפורמט המועדף על Bambu Studio.

Save/Load Project

פורמט .3dpf - JSON metadata + binary meshes, compressed עם fflate. שמירה מלאה של כל ה-state.

Assembly Guide

PDF עם exploded view, חלקים ממוספרים, הוראות הרכבה. לפרויקטים מפוצלים.

תלויות

תלוי ב:
  • שלב 1 - Part Tree (מבנה חלקים), meshCache (גאומטריות)
  • שלב 2 - Split results (חלקים מפוצלים עם connectors)
  • Electron preload - window.api.saveFile() לדיאלוג שמירה

איך נתקוף את השלב

שלב 6.1: STL Export (הכי דחוף)

1. Create STLExporter utility
   - Takes BufferGeometry → Binary STL ArrayBuffer
   - Header (80 bytes) + triangle count (4 bytes) + triangles
2. Export single part (selected)
3. Export all printable parts (batch)
4. Wire to Toolbar "Save" → shows export dialog
5. Options: binary/ASCII, scale factor, coordinate system

שלב 6.2: Project Save/Load

1. ProjectSerializer.serialize(state) → .3dpf file
   - JSON: part tree, dimensions, profile, cloner settings
   - Binary: meshCache geometries as ArrayBuffers
   - Compress with fflate → single ZIP file
2. ProjectSerializer.deserialize(file) → state
   - Unzip, parse JSON, rebuild meshCache
3. Wire to New/Open/Save buttons

שלב 6.3: 3MF Export

1. Build 3MF XML (OPC package)
   - [Content_Types].xml
   - 3D/3dmodel.model (mesh data)
   - _rels/.rels
2. Each part as separate mesh object
3. Package with fflate as ZIP
4. Bambu Studio compatibility testing

שלב 6.4: Assembly Guide

1. Generate exploded view (parts spread apart)
2. Number each part
3. Render screenshot of exploded view
4. Generate PDF with part list + assembly order
5. Include connector info + orientation markers

דרישות חובה לייצוא

כלל ברזל
  • כל mesh מיוצא חייב להיות manifold (watertight)
  • Binary STL מועדף (קבצים קטנים יותר פי 5)
  • Units: מילימטרים (1 unit = 1mm)
  • Coordinate system: Y-up (Three.js default)
