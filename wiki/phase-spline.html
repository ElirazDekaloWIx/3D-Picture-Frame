שלב S: Spline Frames

מערכת צורות מסגרת - מלבן, עיגול, אליפסה, מצולע, ציור חופשי. ניתוב path + הוצאת פרופיל.

80% הושלם

מהות השלב

בשלב 1 המסגרת הייתה תמיד מלבנית. שלב S מרחיב את זה לכל צורה אפשרית. הרעיון: מסגרת = path סגור (2D) + חתך פרופיל שמוצא לאורכו.

Rectangle

4 צלעות ישרות. שיטת Beam + Miter Cut - כמו בניית מסגרות אמיתית. חיתוך ב-45° בפינות.

Circle

Path מעגלי עם CatmullRomCurve3. 128 segments. חלק לחלוטין.

Ellipse

כמו Circle אבל עם radiusX ≠ radiusY. מסגרת אובלית.

Polygon

3-12 צלעות. שיטת Beam + Miter. זווית ה-miter משתנה לפי מספר הצלעות.

Freehand

ציור חופשי על canvas. Chaikin smooth. מסגרת בכל צורה שתרצה.

SVG Import (עתידי)

ייבוא path מקובץ SVG. Bezier curves. Scale/fit אוטומטי.

הרעיון המרכזי: שתי שיטות בנייה

החלטה ארכיטקטונית קריטית

צורות עם צלעות ישרות (מלבן, מצולע) משתמשות ב-Beam + Miter Cut - כל צלע היא קורה נפרדת עם חיתוך מדויק בפינות. צורות מעוקלות (עיגול, אליפסה, freehand) משתמשות ב-SplineExtruder - פרופיל מוצא לאורך curve רציף.

למה שתי שיטות?

ניסינו SplineExtruder לכל הצורות. הפינות יצאו מעוגלות. הסיבה: CatmullRomCurve3 מחליק עיקולים, ו-computeVertexNormals() ממצע normals. כמו שמסגרות אמיתיות נבנות מקורות ישרות עם חיתוך בזוויות - כך גם אנחנו.

אלגוריתמים

Beam + Miter Cut (מצולעים)

לכל צלע במצולע:
  1. חשב exteriorAngle מ-dot/cross product
  2. miterAngle = exteriorAngle / 2
  3. בנה קורה ישרה עם חתך הפרופיל
  4. בכל קצה: הזז vertices לפי tan(miterAngle)
     widthOffset = (u - 0.5) * frameWidth
     miterShift = widthOffset * tan(miterAngle) * sign
  5. 0.1mm overlap בין קורות למניעת פערים
  6. ללא cap faces (הפינות מכוסות ע"י חפיפה)

SplineExtruder (עקומות)

1. הגדר path כ-CatmullRomCurve3 (closed=true)
2. דגום N נקודות מרווחות שווה (N=128 לעיגול)
3. בכל נקודה: חשב tangent + outward normal
   outward = (-tangent.y, tangent.x, 0)  // ניצב ב-XY
4. הנח טבעת vertices של הפרופיל בכל נקודה
5. חבר טבעות סמוכות במשולשים
6. סגור לולאה (טבעת אחרונה → ראשונה)

Chaikin Smoothing (Freehand)

לכל iteration (0-5 levels):
  לכל זוג נקודות סמוכות P[i], P[i+1]:
    Q1 = 0.75 * P[i] + 0.25 * P[i+1]
    Q2 = 0.25 * P[i] + 0.75 * P[i+1]
    החלף את P[i]→P[i+1] ב-Q1, Q2

Result: כפול נקודות בכל iteration, עקומה חלקה יותר
